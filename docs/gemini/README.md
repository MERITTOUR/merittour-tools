## 1. 프로젝트 만들기 — Drive 「프로젝트」 기준 (2026-11-03 화면: 프로젝트 소스 · 기록 · 「Gemini가 소스를 검색하도록 허용」 · Gemini에 질문)

Drive 의 프로젝트는 **소스(파일 · Gmail 대화)에 근거해 답하는 작업 공간**이고, Gem 처럼 지침 칸이 따로 없습니다. 그래서 지침도 소스 문서로 넣습니다.

1. 공유 드라이브의 폴더 **「홍보 제작 소스」**에 이 묶음의 파일을 **Google 문서로 변환해** 넣습니다(md · txt 그대로보다 Docs 가 잘 읽힙니다). **2026-11-04 에 아래 9개를 넣어 두었습니다** — 원본이 바뀌면 같은 이름으로 다시 올립니다. 이름은 읽는 순서대로: `00_프로젝트 지침` · `01_브랜드 가이드` · `02_표기 규칙` · `03_2027 상품 요약` · `04_2027 안내문 본문` · `05_회사 소개 본문` · `06_리조트 안내·식사 본문` · `07_손님 FAQ` · `08_사진·영상 소스`.
2. 프로젝트 「메리트투어 통합 프로젝트」 → 프로젝트 소스 → **추가** → 그 폴더(또는 파일 9개)를 넣습니다. 기존 홍보물 최종본(PDF · 이미지)이 있으면 함께.
3. **「Gemini가 소스를 검색하도록 허용」(Drive · Gmail · Chat · 캘린더 · Google 검색) 토글은 끄는 것을 권장**합니다. 켜면 공유 드라이브의 계약서 · 회원 자료 · 정산 파일과 Gmail 의 손님 메일까지 근거로 끌어와 홍보물에 섞입니다. 꼭 필요하면 Drive 만, 그것도 자료실을 §8 처럼 나눈 뒤에.
4. 대화를 시작할 때 첫 줄에 **「소스의 00_프로젝트 지침을 따라 줘」**를 붙입니다(프로젝트가 지침을 기억하지 못하므로 새 대화마다). `prompts.md` 의 틀은 그 아래에.
5. 공유는 워크스페이스 안의 직원만(「공유」 버튼 · 외부 금지). 홍보물 최종본은 §4 의 8번처럼 Drive 에 보관하고 다음 소스로 씁니다.
6. 같은 지침으로 **Gem 하나를 더 만들어 두면** 소스 없이 빠르게 문안만 쓸 때 편합니다(Gemini 앱 → Gem 만들기 → `project_instructions.md` 붙여 넣기 → 파일 ①②④ 첨부). 프로젝트는 「사실 근거가 필요한 글」, Gem 은 「문장 다듬기 · 짧은 메시지」로 나눠 쓰면 됩니다.
7. 긴 자료를 많이 참고하는 교육·검토용으로는 NotebookLM 에 같은 소스로 노트북을 하나 만들어 두면(출처 표시 · 오디오 요약) 직원 교육에 쓸 수 있습니다. 소스는 같은 파일을 씁니다.

## 4. 홍보물 한 건을 만드는 순서

1. **브리프** — 대상(전 회원 / 특정 회원권 / 신규 모집 / 제휴처) · 목적 · 채널(카카오톡 채널 · 알림톡 · 인스타그램 · 블로그 · 유튜브 · 리플릿 · 카드뉴스 · 메일) · 길이 · 발송·게시 날짜 · 꼭 들어갈 사실.
2. **초안** — `prompts.md` 의 틀로. 「확인 필요」 목록이 같이 나온다.
3. **사실 대조** — 숫자·날짜·조건을 `guide_2027.txt`(또는 안내문 페이지)와 한 줄씩 대조. [확인 필요]를 전부 지운다.
4. **표기 검토** — `style_guide.md` 대로인지(이름 · 라운딩 · 기간 이름 · 회원님 주어 · 인사말 한 번).
5. **디자인** — 실제 사진(③·⑨) + 로고(⑪). 생성 이미지는 배경·아이콘·장식에만. 규격은 `brand_guide.md` 6절.
6. **승인** — 담당자 1명 + 대표. 가격·혜택이 들어간 것은 반드시.
7. **발송·게시** — 채널별 담당.
8. **보관** — 최종본을 Drive 홍보물 폴더에 「날짜_채널_제목」으로 저장하고, 다음 작업의 소스 ⑩ 으로 쓴다.

## 5. 이미지·영상 규칙 (홍보물은 법적 책임이 따른다)

- 리조트 · 객실 · 코스 · 음식은 **실제 사진만**. AI 생성 이미지를 실제 장소처럼 쓰면 허위·과장 광고가 된다. 생성 이미지는 배경 · 패턴 · 아이콘 · 일러스트 · 카드뉴스 틀에만 쓰고 「이미지는 연출된 것입니다」 한 줄을 둔다.
- 사람 얼굴을 생성하지 않는다. 손님 사진은 동의 없이 쓰지 않는다.
- 로고는 주어진 파일만 쓰고 색·비율·글꼴을 바꾸지 않는다(`brand_guide.md` 2절).
- 영상은 유튜브 3편(③)을 링크로. 저장소·프로젝트에 영상 파일을 올리지 않는다.
- 다른 회사·골프장의 사진·지도·로고는 쓰지 않는다. 골프장 공식 사진이 필요하면 허락을 받고 출처를 적는다.

## 6. 표시·광고 체크(발송 전)

- 가격은 「~부터」 + 기준(1인 · 1박 · 2인 1실 · 포함 사항 · 환율 조건)을 함께. 기준 없는 「190만 원!」은 안 된다.
- 「최고」「최저가」「100%」「완벽」「무조건」 금지. 「가성비 좋은」처럼 비교급 없이.
- 회원 전용 상품은 「회원님 대상」, 우선예약·상시예약 기간, 회원권별 조건(포틴힐즈 EWRC 전용 등)을 밝힌다.
- 취소·변경 규정과 문의처(02-365-9800 · 카카오톡 채널)를 넣는다. 카카오톡 메시지는 수신 거부 안내가 자동으로 붙는지 확인.
- 날짜·요일·금액을 안내문과 대조했는지 체크.

## 7. 운영
