## 1. 프로젝트 만들기

1. Gemini 에서 새 프로젝트(없으면 Gem)를 만들고 이름 「메리트투어 홍보·안내 제작실」.
2. 지침 칸에 `project_instructions.md` 의 코드 블록을 그대로 붙여 넣습니다.
3. 소스(파일)에 아래 §2 의 파일을 올립니다. 파일 수 제한이 있으면 **①②③④⑥(guide_2027) 다섯 개가 우선**이고, 나머지는 필요할 때 대화에 붙여 넣습니다.
4. 공유 범위는 워크스페이스(메리트투어) 안으로만. 외부 링크 공개는 끕니다.
5. 사진이 많이 필요한 작업(카드뉴스 · 리플릿)은 Drive 「통합 자료실 › 리조트_사진」 폴더에서 **쓸 장만** 골라 대화에 붙입니다. 폴더째 소스로 올리지 않습니다(용량 · 섞임).
6. 긴 자료를 많이 참고해야 하면 NotebookLM 에 같은 소스로 노트북을 만들어 두고, 글은 Gemini 프로젝트에서 씁니다(둘의 소스는 같은 파일을 쓴다).

## 4. 홍보물 한 건을 만드는 순서

1. **브리프** — 대상(전 회원 / 특정 회원권 / 신규 모집 / 제휴처) · 목적 · 채널(카카오톡 채널 · 알림톡 · 인스타그램 · 블로그 · 유튜브 · 리플릿 · 카드뉴스 · 메일) · 길이 · 발송·게시 날짜 · 꼭 들어갈 사실.
2. **초안** — `prompts.md` 의 틀로. 「확인 필요」 목록이 같이 나온다.
3. **사실 대조** — 숫자·날짜·조건을 `guide_2027.txt`(또는 안내문 페이지)와 한 줄씩 대조. [확인 필요]를 전부 지운다.
4. **표기 검토** — `style_guide.md` 대로인지(이름 · 라운딩 · 기간 이름 · 회원님 주어 · 인사말 한 번).
5. **디자인** — 실제 사진(③·⑨) + 로고(⑪). 생성 이미지는 배경·아이콘·장식에만. 규격은 `brand_guide.md` 6절.
6. **승인** — 담당자 1명 + 대표. 가격·혜택이 들어간 것은 반드시.
7. **발송·게시** — 채널별 담당.
8. **보관** — 최종본을 Drive 홍보물 폴더에 「날짜_채널_제목」으로 저장하고, 다음 작업의 소스 ⑩ 으로 쓴다.

## 5. 이미지·영상 규칙 (홍보물은 법적 책임이 따른다)

- 리조트 · 객실 · 코스 · 음식은 **실제 사진만**. AI 생성 이미지를 실제 장소처럼 쓰면 허위·과장 광고가 된다. 생성 이미지는 배경 · 패턴 · 아이콘 · 일러스트 · 카드뉴스 틀에만 쓰고 「이미지는 연출된 것입니다」 한 줄을 둔다.
- 사람 얼굴을 생성하지 않는다. 손님 사진은 동의 없이 쓰지 않는다.
- 로고는 주어진 파일만 쓰고 색·비율·글꼴을 바꾸지 않는다(`brand_guide.md` 2절).
- 영상은 유튜브 3편(③)을 링크로. 저장소·프로젝트에 영상 파일을 올리지 않는다.
- 다른 회사·골프장의 사진·지도·로고는 쓰지 않는다. 골프장 공식 사진이 필요하면 허락을 받고 출처를 적는다.

## 6. 표시·광고 체크(발송 전)

- 가격은 「~부터」 + 기준(1인 · 1박 · 2인 1실 · 포함 사항 · 환율 조건)을 함께. 기준 없는 「190만 원!」은 안 된다.
- 「최고」「최저가」「100%」「완벽」「무조건」 금지. 「가성비 좋은」처럼 비교급 없이.
- 회원 전용 상품은 「회원님 대상」, 우선예약·상시예약 기간, 회원권별 조건(포틴힐즈 EWRC 전용 등)을 밝힌다.
- 취소·변경 규정과 문의처(02-365-9800 · 카카오톡 채널)를 넣는다. 카카오톡 메시지는 수신 거부 안내가 자동으로 붙는지 확인.
- 날짜·요일·금액을 안내문과 대조했는지 체크.

## 7. 운영

- 담당 1명이 프로젝트의 소스 파일 날짜를 월 1회 확인하고, 안내문이 바뀌면 `guide_2027.txt` 를 그날 교체한다(ChatGPT 쪽 GPT 의 지식 파일도 같이).
- 표기 규칙은 `style_guide.md` 한 파일로 ChatGPT · Gemini 가 같이 쓴다 — 고치면 두 곳 다 교체.
- 좋은 결과가 나온 프롬프트는 `prompts.md` 에 보탠다. 원본은 도구함 저장소 `docs/gemini/`.
