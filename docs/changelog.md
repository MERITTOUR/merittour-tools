## 다음 할 일

- **초대 메일 SMTP** — Supabase 기본 SMTP 는 팀 멤버 주소로만 가고 시간당 제한이 있다.
  지금은 마스터가 콘솔에서 계정을 직접 만들어 아이디·첫 비밀번호를 전달하는 방식으로 돌린다.
  커스텀 SMTP(네이버웍스·구글)를 붙이면 초대 링크 방식으로 돌아갈 수 있다.
  로그인 화면의 초대·재설정 링크 처리 코드는 **지워 두지 않았다** — SMTP 만 붙이면 그대로 산다.
- **환율 계산기** — 하나은행 현찰살때 환율 기반. 관리자 허브에 「준비 중」 카드로만 있었고 만들지 않았다.
  대시보드의 **리조트 마스터 → 월별 환율·항공요금** 표가 실제로 쓰이는 자리이니,
  별도 도구를 새로 만들지 말고 그 표를 채우는 흐름을 손보는 편이 낫다.
  기준일 = **출발 2달 전 월 1일자(2026 · 2027 동일)** — 2027 부터 3달 전으로 두는 안은 2026-09-07 에 되돌렸다.
- **엠클릭 API 통합** — 엠클릭 대표와 협의 중. API 가 열리면 엑셀 업로드 단계가 사라진다.
- **항공팀·관리팀 도구 정의** — 두 허브가 비어 있다. 필요한 도구를 정리한 뒤 채운다.
- **Supabase 마이그레이션 08~11** — 콘솔에만 있고 저장소에 없다. 새 환경을 만들 때 빠진다.
- **클라우드 서버 도입** — ₩10,000~30,000/월. 자동 스케줄 발송 등.
- **SaaS 확장(장기)** — 다른 한국 골프 투어 운영사 대상.
