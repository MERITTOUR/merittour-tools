# 08 · 실제 담당자 확인이 필요한 질문 (Open Questions)

> 코드만으로 확정 불가하거나, 문서·코드가 불일치하는 지점. **답에 따라 인수인계·통합 방향이 갈림.**

## A. Supabase / 자동화 실사용 여부 (가장 중요)
1. **예약 동기화(`reservations`)를 실제로 쓰는 PC가 있나?** — 각 PC `mt_doc_cfg`에 Supabase URL/anon key가 입력돼 있어야만 동작. 지금 운영에서 켜져 있는지? (코드만으론 불가)
2. **D-7 항공/PNR 자동발송이 실제 가동 중인가?** — Edge Function 배포 + 알리고/CRON_SECRET 시크릿 + 카카오 템플릿 승인 + cron 등록 + 데이터 동기화가 **모두** 충족돼야 발송. 실제 손님에게 나가고 있나? (⚠ 향후 기능일 가능성)
3. **confirm-docs(확정서 링크·알림톡)를 실제로 쓰나?** — 버킷·Edge Function·템플릿 설정 여부. 안 쓰면 "향후 기능".
4. **confirm-docs 버킷은 실제 public인가 private인가?** — 저장소에 상충 SQL 2개(`storage.sql`=private, `storage_policy.sql`=public). 실제 운영 버킷 설정 확인 필요.
5. **`send-alimtalk` Edge Function을 실제 호출하나?** — `aligoEndpoint` 미입력 시 알리고 엑셀 폴백. 실제 발송 경로가 어느 쪽인지.
6. **`resort_master` 테이블(서버)** — 현재 클라이언트 호출 0건(정의만 존재). 실제 사용 중인지, 아니면 미사용 인프라인지?

## B. 문서 vs 코드 불일치
7. **inquiry(예약가능일자) 도구** — CLAUDE.md는 "폐지", 코드는 v1.2 현역 + admin 카드 노출. 실제로 쓰나, 폐지인가?
8. **환율 기준: 2달 전 vs 3달 전** — 대시보드·CLAUDE.md는 "2달 전", 고객 안내문은 "세 달 전". 정확한 실제 기준은?
9. **booking 프로토타입에 게이트 없음** — 손님/벤더에게 공개돼도 되는지(내부 시연용인데 URL 공개 상태).
10. **`tools/saizen/`·`tools/aligo/` 폴더 존재 여부** — admin 허브가 링크하나 이번 분석 범위 밖. 실제 존재/동작?

## C. 업무 규칙 확정
11. **그린피·식사 단가가 전부 0(미입력)** — 이 항목들을 실제로 쓰는지, 요금에 반영해야 하는지?
12. **현지정산단가 기본식 `체재비 − ¥1,000`** — 이 −1,000 규칙이 현행 실무와 맞나?
13. **패키지 프리셋 우회** — 벳푸/나가노처럼 단일가로 안내하는 상품 목록이 확정돼 있나?
14. **상품 패턴(출발요일·박수)** — 리조트별 2027 실제 운영 패턴(벳푸 일→금 5박, 나가노 목→목 7박 등)이 최신인지.

## D. 데이터·운영

17. **다운로드 파일명 한글 사용분**(마스터 JSON·안내문 JPG·알리고 XLSX) — 다운로드 실패 사례 있었나?
