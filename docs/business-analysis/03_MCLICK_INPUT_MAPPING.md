# 03 · M클릭 입력 매핑 (Mclick Input Mapping)

> 기준: `tools/dashboard/index.html`, `tools/insurance/index.html`. ✅ 코드 확정.
> 코드는 **컬럼 위치(idx)가 아니라 한글 헤더명**으로 읽음(SheetJS `sheet_to_json`이 헤더행을 키로 사용). 각 파일은 **첫 시트만** 읽음(`SheetNames[0]`).

## 입력 2종
| 입력 | 엠클릭 출처 탭 | 다운로드 단위 | 대시보드 변수 |
|---|---|---|---|
| **예약리스트** | 출발일별/예약일별 → **예약현황** 탭 | 500행씩 분할(여러 파일) | `resData` |
| **일행별예약** | 출발일별/예약일별 → **탑승자정보** 탭 | 1개월 단위(인원 무관) | `ilhaengData` |
- 여러 파일/여러 달은 같은 칸에 올리면 자동 병합. ✅

## 예약리스트(resData)가 읽는 컬럼 ✅
`구분` · `cancCd`(취소코드) · `eventSeq` · `상품명` · `비고` · `현지 비고` · `기타 비고` · `출발일자` · `도착일자` · `기간` · `호텔`(Y/N) · `명단`(Y/N) · `행사번호` · `대표고객` · `회원권구분` · `출발지` · `항공` · `예약`(인원수) · `판매금액` · `미수금액`
- 비고 3종은 `' / '`로 합쳐 팀 자동인식·특이사항 파싱에 사용. (CLAUDE.md의 "idx 30·31·32"는 원본 엑셀 열 위치 메모일 뿐, 코드는 헤더명 기반)

## 일행별예약(ilhaengData)이 읽는 컬럼 ✅
- **항공시각 맵(buildArrivalMap, eventSeq당 대표)**: `출발편` · `귀국편` · `한국출발` · `현지도착` · `현지출발` · `한국도착` · `출발일자` · `도착일자` · `행사번호`
- **항공/여권 맵(buildApisMap, 개인별)**: `PNR` · `영문성` · `영문이름` · `항공사` · `출발편` · `귀국편` · `출발지` · `도착지` · `사전좌석`(Y) · `여권번호` · `만료일` · `발행국가` · `성별` · `생년월일` · `고객명`
- **명단(pax_list)**: `고객명` · `예약자명`(대표자 판별·정렬) · `영문성` · `영문이름` · `생년월일` · `성별` · `휴대번호` · `출발편` · `귀국편`
- 공통 제외: `cancCd`가 있으면 skip.

## 핵심 식별자 ✅
| 식별자 | 소스 | 역할 |
|---|---|---|
| **`eventSeq`** | 두 파일 공통 | **결합 마스터 키(silent join).** `String().trim()` 정규화. arrivalMap/apisMap 키, `teams[].eventSeq`, 명단 그룹핑(`seqGroups`), 모든 수기 오버레이 키(`editOverrides`/`teamAssign`/`vAdjust`/`ticketDone`/`docHotelName`), Supabase `event_seq`. 화면엔 거의 미표시 |
| **행사번호 `eventNo`** | `r['행사번호']` | **사람이 보는 표시키.** 검색·표 표시·확정서 파일명(`{eventNo}.jpg`)·스토리지 경로·알림톡 레코드·정산행 |
| `cancCd` | 두 파일 | 취소코드 — 있으면 집계 제외 |
| 개인 매칭 키 | 정산·보험 | `[행사번호, 성함, 생년6(YYMMDD)]` (생년 없으면 `[행사번호,성함]`) — 항공원가 업로드·보험 매칭에 사용 |

## PNR 처리 ✅
`pnrRaw.replace(/，/g,',').split(',')` — **전각 콤마 `，` 포함 분리 후 전부 수집**(첫 개만 쓰지 않음).

## 보험 도구 입력(tools/insurance) ✅
- 입력 2종: **일행별예약 엑셀**(필수 헤더 `고객명`·`생년월일`·`행사번호`) + **DB손해보험 가입증명서 PDF**.
- 엑셀에서 생년월일 → `bd6`(YYMMDD) 추출(4자리 연도면 뒤 2자리). 이름 NFC 정규화.
- PDF는 pdf.js 좌표 기반 파싱, 2형식(명세 리스트형 `list` / 단일 증명서형 `cert`).

## 지역명 ≠ 실제 공항 (코드 내장) ✅
`AIRPORT_CODE` 매핑: 벳푸=`FUK`(오이타=OIT) · 이바라키/나리타=`NRT` · 나가노/니가타=`KIJ` · 나고야/중부=`NGO` · 구마모토=`KMJ` · 미야자키=`KMI`. 숙소 마스터 `arrCode`가 항공 매칭 기준.
