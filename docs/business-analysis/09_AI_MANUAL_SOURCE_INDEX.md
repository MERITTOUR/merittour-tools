# 09 · 직원 매뉴얼·SOP 재사용 규칙 색인 (AI Manual Source Index)

> 코드로 확정된, **직원 매뉴얼·SOP·AI 어시스턴트 학습자료로 재사용 가능한 규칙** 색인. 각 항목의 근거 문서를 표기. (⚠ 표시 항목은 담당 확정 후 매뉴얼화)

## 1. 기본 조작 SOP
- **접근**: 사이트 최초 진입 시 이름(2글자+)+비밀번호 게이트, 30일 유지(30일 미접속 시 재입력). 비번 변경 시 자동 재입력. → `01` §공유자산, `05`B
- **분석 절차**: 엠클릭에서 예약리스트(예약현황·500행 분할)+일행별예약(탑승자정보·1개월) 다운로드 → 대시보드 업로드(여러 파일 병합) → [통합 분석 실행] → ③검수부터 확인. 새로고침 시 재업로드 필요. → `02`, `03`
- **마스터 배포**: 관리자가 단가·환율·항공요금 입력 → 마스터 내보내기(JSON) → 직원 불러오기 1회. → `05`B, `07`C

## 2. 데이터 규칙 (SOP화 가능)
- **결합 키**: 두 파일은 `eventSeq`로 결합, 사람은 `행사번호`로 식별. → `03`
- **PNR**: 콤마(전각 `，` 포함) 분리 시 전부 기재. → `03`
- **취소 처리**: `구분=취소` 또는 `cancCd` 있으면 집계 제외(조회는 별도). → `04`§1
- **비고 3종**: 비고·현지 비고·기타 비고를 합쳐 팀 자동인식·특이사항 판정. → `03`

## 3. 요금·정산 규칙 (검증·교육용)
- **회원관리비**: 리조트 마스터 숙소별 값이 단일 출처(기본 5만원, 면제 숙소 0). → `04`§4
- **환율**: 월별 테이블(출발월 기준), ⚠ "출발 N달 전 하나은행 현찰 살 때" 기준은 관행(2달/3달 확정 필요). 미등록 월은 검증 제외. → `04`§5, `08`Q8
- **항공요금 매칭**: 도착지는 숙소 `arrCode` 우선. 지역명≠공항 주의(벳푸=FUK·이바라키=NRT·나가노=KIJ). → `03`, `04`§6
- **정산 공식**: 알선수익 = 판매금액 − 항공원가 − 지상비 − 보험료 / 수수료 = 알선수익÷1.1(부가세 역산) / 총수수료 = 수수료 + 체재마진. 공제 후 실정산액. → `04`§7
- **거래유형**: 상품명이 "여행사"로 시작 = B2B. 전 탭 공유 필터. → `04`§2

## 4. 보험 매칭 SOP
- 일행별예약 엑셀 + DB손보 가입증명서 PDF → `이름+생년6` 정확매칭 → 실패분 `생년6` 폴백 → matched/onlyExcel/onlyPdf 3분류. → `04`§9

## 5. 출력물 카탈로그 (담당 안내용)
- PNR 알리고 양식, 확정서/견적서/일정서 JPG, ZIP 일괄, 정산표 XLSX, 블록현황/예약가능일정 PNG, 항공발권 안내문. 고객 발송물은 JPG. → `05`A

## 6. 매뉴얼화 전 확정 필요 (⚠ = 08 문서 질문)
- Supabase/자동발송/confirm-docs 실사용 여부(Q1~5) → 확정 전에는 매뉴얼에 "향후 기능"으로만 기술.
- inquiry 폐지/현역(Q7), 환율 2·3달(Q8), 상품 패턴 최신(Q14).
