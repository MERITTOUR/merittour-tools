# 골프 날씨 웹사이트 — BUILD SPEC

> **대상**: Claude Code 핸드오프 · **산출물**: 단일 자립형 HTML 1개 파일
> **버전**: v1.0 기준 명세 · **작성**: 메리트투어 사내 도구
> **참고 구현체**: `golf-weather_v1.0.html` (동작 확인 완료, 이 스펙과 1:1 대응)

이 문서만으로 처음부터 빌드 가능하도록 작성했습니다. 기존 v1.0을 이어서 개선하는 경우에도 동일 기준을 사용합니다.

---

## 1. 목적과 대상

- **목적**: 골프 손님이 특정 골프장·날짜의 **라운딩 적합도**를 숫자 해석 없이 한눈에 판단하게 한다.
- **사용 주체**: 고객 공개용 + 내부 운영/현장 겸용.
- **대상 고객**: 50~70대 → 큰 폰트, 높은 대비, **색과 글자를 항상 병기**(색맹·저시력 대응).
- **차별점**: 일반 날씨 앱과 달리 "지금 날씨"가 아니라 **티타임 구간(07~15시)의 시간별 흐름**을 종합해 판정한다.

## 2. 산출물 / 기술 스택

- **형식**: 단일 HTML 파일. 인라인 `<style>` + `<script>`. 외부 빌드 도구 없음.
- **의존성**: 순수 JS(프레임워크 없음). 폰트만 CDN 로드.
- **API 키**: 불필요 (Open-Meteo 무료·키리스).
- **저장소**: `localStorage` 등 브라우저 스토리지 **사용 금지**(불필요, 상태는 메모리 변수로 관리).
- **배포**: GitHub Pages / MClick 공지 게시판에 그대로 업로드 가능해야 함.

폰트 로드:

## 3. 외부 API 명세 (Open-Meteo)

### 3.1 예보 API

`GET https://api.open-meteo.com/v1/forecast`

| 파라미터 | 값 | 비고 |
|---|---|---|
| `latitude`, `longitude` | 골프장/검색 좌표 | 필수 |
| `timezone` | `auto` | 현지 시각(JST 등)으로 반환 |
| `forecast_days` | `7` | |
| `wind_speed_unit` | `ms` | **m/s**(일본·골프 관행). 풍속·돌풍·최대풍속 모두 m/s |
| `elevation` | 프리셋 표고(선택) | 고지대 골프장 기온 보정. 검색 결과는 생략(자동 DEM) |
| `current` | 아래 필드 목록 | |
| `hourly` | 아래 필드 목록 | |
| `daily` | 아래 필드 목록 | |

- `current`: `temperature_2m, apparent_temperature, relative_humidity_2m, precipitation, weather_code, wind_speed_10m, wind_direction_10m, wind_gusts_10m`
- `hourly`: `temperature_2m, apparent_temperature, precipitation_probability, precipitation, weather_code, wind_speed_10m, wind_gusts_10m, wind_direction_10m, visibility, uv_index, relative_humidity_2m`
- `daily`: `weather_code, temperature_2m_max, temperature_2m_min, precipitation_probability_max, precipitation_sum, wind_speed_10m_max, uv_index_max, sunrise, sunset`

**응답 특성**
- 시각 문자열은 `"YYYY-MM-DDTHH:00"` 형식(초 없음). "현재 시각" 매칭은 앞 13자(`YYYY-MM-DDTHH`) 비교.
- `precipitation_probability`, `visibility`, `uv_index`는 일부 시각에 `null` 가능 → 항상 `?? 0` / null 가드 처리.
- 단위: 기온 ℃, 강수량 mm, 시정 m, 풍속 m/s, 자외선 무단위.

### 3.2 지오코딩 API (검색)

`GET https://geocoding-api.open-meteo.com/v1/search?name={q}&count=6&language={ko|ja}&format=json`

- 입력 2자 이상, **300ms 디바운스**.
- 응답 `results[]`: `name, latitude, longitude, admin1, country, elevation, timezone`.
- 결과 클릭 시 해당 좌표로 예보 재조회. 검색 지점은 프리셋과 동일 흐름으로 취급.
- `language`는 현재 UI 언어와 연동.

### 5.2 컴포넌트 명세

- **헤더**: 좌측 `MERITTOUR`(kicker) + 타이틀(Noto Serif). 우측 언어 토글(pill).
- **장소 선택**: 프리셋 3개(활성 시 네이비 반전) + 검색창(결과 드롭다운, 바깥 클릭 시 닫힘).
- **① 현재 날씨**: 실시간(now) 기준. 큰 이모지 + 기온 + 상태 텍스트 + 체감. 우측 메트릭: 바람(풍향+풍속), 돌풍, 습도, 자외선, 시정. **자외선·시정은 `hourly`의 현재 시각 인덱스에서 보완**(current 블록엔 없음).
- **② 라운딩 적합도(시그니처)**: **선택일 기준**. 좌측 원형 게이지(SVG, 100점, 신호색), 우측에 날짜 라벨 + 골프 깃대 아이콘(신호색) + 판정어(Noto Serif) + 대표 사유 한 줄. 하단에 5단계 색 스케일 바.
- **③ 시간대별**: 선택일의 05~19시. 셀 = 시각/이모지/기온/강수확률(≥10%만)/풍속 + 하단 점수 바(신호색). **07~15시 셀 배경 강조**(티타임). 하단에 "라운딩 시간대 강조" 범례.
- **④ 7일 예보**: 카드 그리드. 요일·날짜/이모지/**점수 pill(신호색)**/최고·최저/강수확률·최대풍속. 클릭 시 `SEL_DAY` 갱신 → 전체 재렌더 + 상단 스크롤. 오늘/내일 라벨 표기.
- **푸터**: 선택일 일출/일몰, 자료 출처(open-meteo 링크), 갱신 시각.

## 6. 라운딩 적합도 점수 로직 (핵심)

### 6.1 시간별 감점 (기준 100점에서 차감)

| 항목 | 조건 → 감점 |
|---|---|
| 뇌우 (WMO 95/96/99) | −60 |
| 강수확률 | ≥70% −45 / 50–69% −28 / 30–49% −14 / 15–29% −5 |
| 강수량 (mm/h) | ≥4 −40 / 1–4 −20 / 0.2–1 −8 |
| 풍속 (m/s) | ≥10 −35 / 7–10 −20 / 5–7 −10 / 4–5 −4 |
| 돌풍 (m/s) | ≥13 → 추가 −10 |
| 더위 (℃) | ≥35 −30 / 33–35 −18 / 30–33 −8 |
| 추위 (℃) | ≤0 −28 / 0–3 −16 / 3–6 −7 |
| 자외선 | ≥8 −8 / 6–8 −4 |
| 시정 (m) | <1000 −15 / 1000–3000 −6 |

- 최종 시간 점수 = `clamp(0, 100)`.
- 항목별 감점값을 누적 저장(대표 사유 산출용, §6.4).

### 6.2 하루(라운딩 구간) 종합

- 대상 시간대 = `ROUND_START(7) ~ ROUND_END(15)` (07~14시).
- 하루 점수 = 해당 구간 **시간 점수들의 평균**(반올림).
- 구간 내 뇌우 시간이 하나라도 있으면 하루 점수를 **최대 22로 캡**(안전 우선).

### 6.3 판정 밴드 (5단계 신호색)

| 점수 | 판정 KO | 판정 JA | 색 |
|---|---|---|---|
| 85–100 | 라운딩 최적 | ラウンド最適 | `#1b7a3d` |
| 70–84 | 라운딩 좋음 | ラウンド良好 | `#3aa856` |
| 50–69 | 라운딩 보통·주의 | まずまず・注意 | `#e0a100` |
| 30–49 | 라운딩 주의 | 注意 | `#e2620c` |
| 0–29 | 라운딩 비추천 | 非推奨 | `#c0392b` |

### 6.4 대표 사유

- 구간 누적 감점이 **가장 큰 항목**을 사유로 선택. 값 병기:
  - `rain` → 사유 + `(최대 강수확률 %)`
  - `wind` → 사유 + `(최대 풍속 m/s)`
  - `heat` → 사유 + `(최고기온 °)` / `cold` → `(최저기온 °)`
  - 감점 없음 → "특이사항 없음 / 良好"

## 7. 다국어 (한 · 일)

- 상단 토글 `한국어 | 日本語`. 상태 변수 `LANG ∈ {ko, ja}`.
- 문자열은 `I18N[LANG]` 사전 객체로 관리(정적 UI 텍스트, 판정어, 사유, 방위, 요일, 단위).
- **골프 용어 규칙(고정)**: 한국어 = **"라운딩"**(라운드 금지), 일본어 = **「ラウンド」**.
- 방위 8방: KO `[북,북동,동,남동,남,남서,서,북서]` / JA `[北,北東,東,南東,南,南西,西,北西]`. `deg → dirs[round(deg/45)%8]`.
- 검색 언어(`language`)·날짜 로케일도 `LANG` 연동.

## 10. 대기 · 시간대 · 날씨 애니메이션

전체를 **산뜻하고 밝은 날씨앱 감성**으로 만든다. 콘텐츠 뒤에 **살아있는 하늘(sky) 레이어**를 깔아 ① 해당 지역의 **현지 시간대**와 ② **현재 날씨 상태**에 따라 배경·요소가 부드럽게 변한다. 은은하고 세련되게("틱하게") — 과하지 않게.

### 10.1 레이어 구조 (z-index 낮→높)

```
.sky  (position:fixed, 화면 전체 배경)
 ├─ .sky-gradient   시간대별 하늘 그라데이션 (phase 변경 시 CSS transition ~1.2s)
 ├─ .celestial      해 / 달 (일출~일몰 진행도로 아크 이동 + 글로우)
 ├─ .stars          별 (밤에만, 느린 반짝임)
 ├─ .clouds         흐르는 구름 (조건부)
 ├─ .precip         비 / 눈 파티클 (조건부, JS로 1회 생성)
 └─ .flash          번개 플래시 (뇌우 시)
[콘텐츠·흰색 카드]  ← 이 레이어 위에 렌더 (가독성 우선)
```

### 10.2 시간대(Phase) — **반드시 "해당 지역 현지 시각" 기준**

- 판정 소스: `timezone=auto`로 받은 `current.time`(이미 현지 시각) + 선택 지역 **당일 `sunrise`/`sunset`**. **뷰어 기기 시각을 사용하지 않는다.**
- 현지 시각과 일출/일몰로 5단계 산출(밝은 계열이 지배적):

| phase | 조건(현지) | 하늘 그라데이션 |
|---|---|---|
| 밤 `night` | 일몰+0.75h 이후 ~ 일출−0.5h | 심청색 인디고(검정 아님) + 별·달 |
| 새벽 `dawn` | 일출−0.5h ~ 일출+1h | 라벤더 → 피치, 낮은 해 |
| 아침 `morning` | 일출+1h ~ 정오 | 맑은 하늘색, 따뜻한 저각 해 |
| 낮 `midday` | 정오 ~ 일몰−1.25h | 밝은 스카이블루, 높은 해 |
| 석양 `golden` | 일몰−1.25h ~ 일몰+0.75h | 코랄 → 오렌지 |

- phase 전환은 CSS 변수 교체 + `transition`으로 부드럽게.
- 참고 팔레트(밝게, 조정 가능):
  `dawn` `#f7c9c9→#ffe3c2` / `morning` `#bfe3ff→#eaf6ff` / `midday` `#7cc4f2→#cfeaff` / `golden` `#ff9e6d→#ffd29e` / `night` `#1a2340→#2b3a63`.

### 10.3 해 / 달 아크 이동

- **해**: 진행도 `p = (now − sunrise) / (sunset − sunrise)` (0~1)을 반원 아크(좌하 → 상단 → 우하)에 매핑해 위치. 부드러운 radial-gradient 글로우.
- **달**: 밤에는 `(now − sunset) / (익일 sunrise − sunset)`로 동일 아크. 은은한 별(작은 점 다수, 느린 opacity 반짝임).
- 재계산은 phase/조건 변경 시 또는 수 분 간격 폴링으로 충분(초당 갱신 불필요).

### 10.4 날씨 조건 오버레이 (WMO 기준)

현재 `weather_code`로 오버레이 선택. 파티클은 **조건 변경 시 1회 생성**(렌더마다 재생성 금지).

| 상태 | 코드 | 애니메이션 |
|---|---|---|
| 맑음 | 0, 1 | 은은한 햇살 shimmer, 전체 밝게 |
| 구름 조금 | 2 | 구름 2~3개 느린 드리프트 |
| 흐림 | 3 | 구름 다수 드리프트, 채도 약간 낮춤 |
| 안개 | 45, 48 | 반투명 haze 층(soft blur / 낮은 opacity) |
| 이슬비·비 | 51–67, 80–82 | 대각 빗줄기 낙하. 강도 스케일(이슬비=옅게, 강한 비=촘촘) |
| 눈 | 71–77, 85, 86 | 느린 눈송이 낙하(좌우 흔들림) |
| 뇌우 | 95, 96, 99 | 비 + 간헐 번개 플래시(opacity 순간 상승, 잔잔한 간격) |

- 파티클 상한(모바일 성능): **비 ≤ 60, 눈 ≤ 40**. 위치·낙하 지연·속도 랜덤화.
- **`transform: translateY` / `opacity`만** 사용(레이아웃 리플로우 금지). GPU 가속 유도.
- 강도는 강수확률/강수량 또는 코드 등급으로 스케일 가능(선택).

### 10.5 성능 · 접근성

- **`prefers-reduced-motion: reduce`**: 파티클·드리프트·아크 이동 **중지**, 정적 그라데이션 + 정적 상태 아이콘만 유지.
- 탭 비활성(`visibilitychange`) 시 애니메이션 일시정지 권장.
- 콘텐츠·텍스트 대비는 **어떤 phase에서도** 확보(흰 카드 위 렌더 원칙, 50~70대 가독성 우선).

## 13. 확인 필요 사항

1. **벳푸 프리셋 좌표** — "아키바 리조트" 실제 라운딩 코스명 확정 후 정밀 좌표로 교체. (오기야마 컨트리클럽 제외 방침 반영)
2. **점수 임계값 보정** — 고령 고객 기준으로 더위/추위·풍속 구간을 더 보수적으로 조정할지 여부(현재값은 §6.1).
3. **티타임 구간** — 실제 팀 배정 시간대(07~15시)가 상품별로 다르면 상수 조정 또는 골프장별 개별 설정.
4. **헤더/푸터 처리** — 네이비 유지(브랜드 표준) vs 하늘에 녹인 반투명(밝은 앱 감성). 택1. 기본 권장은 네이비 유지.
5. **애니메이션 강도 기본값** — `soft`(은은, 기본) vs `vivid`(뚜렷). §12 `ANIM_INTENSITY`.
