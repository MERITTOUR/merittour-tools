# MERITTOUR 사내 도구함

엠클릭(Mclick) 데이터를 기반으로 영업·운영 업무를 돕는 단일 HTML 도구 모음입니다.
GitHub Pages로 배포되며, 진입점은 영업 도구함(`/sales/`)입니다.

## 도구 목록 (`tools/`)

| 도구 | 경로 | 설명 |
|---|---|---|
| 통합 업무 허브 | `tools/dashboard/` | 엠클릭 데이터를 한데 모아 예약·항공·확정서·정산·요금검증·호텔블록을 한 화면에서 점검하는 메인 도구 |
| 보험코드매칭 | `tools/insurance/` | 보험사 PDF + 예약 엑셀 → 인별/행사별 보험료 자동 매칭 |
| 이미지 툴킷 | `tools/imgtoolkit/` | WebP 변환·리사이즈·압축. 엠클릭 백오피스용 이미지 최적화 |
| 리조트 날씨 | `tools/weather/` | 리조트별 현지 날씨 예보 + 손님 안내문 복사 |
| 가입 서류 자료실 | `tools/library/` | EWRC2·장기숙박형 숙소(쿠주힐즈) 신규 가입 서류 안내 + `archive/` 회원권·서류 버전 이력 |

> 기존 `예약가능일자 안내(inquiry)` 도구는 통합 업무 허브의 ② 호텔 블록 탭으로 흡수되었습니다(폴더는 잔존).

## 통합 업무 허브 (dashboard)

엠클릭 데이터를 한데 모아 더 편하게 점검·집계·발송 대상 추출을 하는 메인 도구입니다.
엠클릭이 본체 ERP이고, 이 도구는 그 데이터를 모아 조회·검증을 보조합니다.

### 받는 파일 (엠클릭 2종, eventSeq로 결합)

| 파일 | 필수? | 엠클릭 다운로드 위치 | 비고 |
|---|---|---|---|
| 예약리스트 | 필수 | 출발일별 / 예약일별 → **예약현황** 탭 | 구분·호텔·명단·미수금·판매금액·비고 |
| 일행별예약 | 필수 | 출발일별 / 예약일별 → **탑승자정보** 탭 | 개인(탑승객) 명단 + 항공시각·PNR·항공사·출발/귀국편·사전좌석·여권 통합 |

예약리스트는 한 번에 500행씩 다운로드되어 건수가 많으면 나눠 받고, 일행별예약은 1개월 단위로 명단 인원수와 무관하게 한 번에 받습니다. 여러 달이거나 분할분이 생기면 같은 칸에 여러 개 올리면 자동 병합됩니다. 그룹코드 마스터는 사용하지 않습니다.

> 엠클릭 컬럼 정리로 **예약리스트 + 일행별예약 2종**만으로 동작합니다(2026-06 통합 완료). 항공시각 4종(한국출발·현지도착·현지출발·한국도착)·PNR·항공사·출발/귀국편·출발지/도착지·사전좌석·여권번호·만료일·발행국가가 일행별예약 한 파일에 흡수되어, 구 APIS·현지도착 파일은 폐지되었습니다.

### 섹션 (실제 내비게이션 순서)

활성 6개 + 준비중 7개 구조입니다. 활성 섹션에는 원형 번호(①~⑥)가, 준비중 섹션에는 「준비중」 배지가 붙습니다(준비중 섹션도 기능은 구현돼 있고 통합 분석 실행 시 동작). 확정서 생성·정산은 기능 완성도가 높으나 UI 마감·배포 정책상 준비중으로 분류했습니다.

```
업로드 → ① 리조트 마스터 → ② 호텔 블록 → ③ 데이터 검수 → ④ 요금 관리
→ ⑤ 예약 관리 → ⑥ 항공 정보 ┊ (준비중) 확정서 생성 · 정산 · 보험 · 송영 · 숙소 · 골프 · 식사
─ 구분선 ─
(준비중) 보험 정보 · 송영 정보 · 숙소 정보 · 골프 정보 · 식사 정보
```

1. **리조트 마스터** — 숙소별 단가(체재·송영·그린피·식사)·현지정산단가·회원관리비·출발 일정·공항·도착코드. 공통 마스터(월별 환율 테이블·항공요금 테이블[안내 요금+발권원가]·변경 이력). 마스터 JSON 내보내기/불러오기로 직원 간 기준값 공유(서버 불필요).
2. **호텔 블록** — 엠클릭 「호텔별 예약현황」 표를 붙여넣어 즉석 분석. 블록 현황(보유−사용=잔여)·출발 가능 일정 조회·대기 전환 점검·판매 시뮬레이션·전기카트.
3. **데이터 검수** — 엠클릭 수기 입력 오류(영문명 공백·여권 만료 임박·PNR 누락 등)를 발권 전에 검출(자동 수정 없음, 화면 표시 전용).
4. **요금 관리** — 요금 달력(정방향 산출)이 기본 뷰, 표 보기(역방향 검증)가 두 번째. 리조트 마스터 단가 × 월별 환율 + 항공요금으로 예상 판매금액 산출 → 실제와 대조. 패키지가(1인) 우회·프리셋 지원.
5. **예약 관리** — 전체 현황·호텔/명단/미수금, 비고 팀 구분 모달, 출국 임박(D-30/7/1) 모달, 알리고 양식 내보내기, 취소건 조회(별도 보존·집계 제외).
6. **항공 정보** — 일행 전원·항공사·편명·사전좌석·PNR(콤마 전부)·발권완료 체크. 점검 칩(PNR미등록·사전좌석Y·편명누락·항공사불일치).
7. **확정서 생성** — 견적서/일정표/확정서 3종(v7 인터랙티브 HTML). 보딩패스 히어로·팀/개인 토글·D-day·KakaoTalk 입금 버튼·숙소 복사. 일정 타임라인은 첫날(출국)·마지막날(귀국)을 항상 펼치고 **중간 2일차~귀국 전날은 「N~M일차 라운딩 일정」 접이식**으로 기본 접힘. 개별 `{행사번호}.html` 다운로드 + 선택 팀 ZIP(JSZip). 16개 골프투어 상품 마스터 키워드 매칭. (GitHub `confirm/` 업로드 워크플로우는 향후 과제)
8. **정산** — **현지정산(¥) 단일 화면에 수익 통합**. 구분 칩 체크박스(견적·대기·확정·정산·취소 중 선택)로 대상 필터. 명세표에 체재마진(¥)·항공안내가(₩)·항공원가(₩, 입력)·항공수익(₩)·총수익(₩) 컬럼. 항공원가는 행별 직접 입력 또는 입력틀 엑셀 내보내기→채워서 불러오기(행사번호+성함+생년월일 매칭). 차감 관리·정산표 엑셀.

준비중(보험·송영·숙소·골프·식사)도 렌더 함수가 구현돼 통합 분석 시 동작합니다. 특히 **보험 정보**는 DB손해보험 전원 기본 가입(필수) 구조로 개편 완료(가입정보 생년월일·성별만, 제외 요청자만 개인 단위 제외).

### 알리고 PNR 안내 양식

예약 관리 또는 항공 정보에서 발송할 팀을 체크하고 [선택 팀 알리고 양식] 버튼을 누르면,
알리고 알림톡 업로드용 xlsx가 생성됩니다(수신번호 + 고객명·일자·상품명·출발지·도착지·편명·PNR).
체크인 타이밍·공항 도착·카운터 안내 문구는 알리고 템플릿이 처리하므로, 도구는 치환변수만 채웁니다.

## 데이터 저장·공유

- 모든 입력값은 **localStorage**에 저장됩니다(키 네임스페이스 `mt_notify_*` / `mt_settle_*` / `mt_doc_*` / `mt_edit_overrides`).
- 리조트 마스터 등 기준값의 직원 간 공유는 **JSON 마스터 내보내기/불러오기**로 합니다(서버·키 불필요).
- `supabase/resort_master_setup.sql`에 클라우드 공유용 스키마(테이블 2개 + RLS)가 준비돼 있으나 **아직 코드에 연결되지 않았습니다**(엠클릭 헤더명 정리·2종 통합 완료 후 착수 예정). 현재 RLS 쓰기 정책이 always-true이므로 적용 시 먼저 잠가야 합니다.

## 기술 표준

- 단일 HTML 파일 기반. 외부 라이브러리는 CDN(cdnjs)에서 로드(xlsx=SheetJS, html2canvas, JSZip, pdf.js)
- 로고는 인라인 SVG, 데이터 저장은 localStorage
- 라이트 모드 고정, 메리트투어 네이비/블루그레이 색상 표준

## 접근 제어

- `shared/gate.js` — 비밀번호(SHA-256) + 이름 입력 가림막. 비밀번호 통과는 sessionStorage, 이름은 localStorage. 정적 GitHub Pages라 강한 보안이 아니라 "URL 우연 노출 가림막 + 협업용 서명" 용도. 현재 sales·dashboard에 적용(admin·air·manage는 미적용 — 향후 과제).
- `auth.js` — Google 로그인 화이트리스트(현재 `ENABLED:false` 비활성). 강한 보안 필요 시 활성화 또는 서버 사이드(Cloudflare Access 등) 전환 검토.
- `robots.txt` — 전체 크롤링 차단(`Disallow: /`).
