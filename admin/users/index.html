계정 관리

계정을 승인하고 역할과 볼 수 있는 화면을 정합니다.
초대 메일은 Supabase 콘솔 → Authentication → Users → Invite user 에서 보냅니다.

로그인: ← 도구 화면
자료 권한과 섹션은 다른 층입니다. 자료 권한은 서버에서 무엇을 저장·삭제할 수 있나(자료 등록·리조트 마스터·예약·확정서)를 정하고, 섹션은 어느 화면을 여나를 정합니다. 둘 다 있어야 실제로 일이 됩니다.
자료 권한 — 마스터(계정 승인·권한 변경, 전부 가능) · 관리팀 · 영업팀(자료 등록·수정) · 항공팀(읽기 전용). 권한 관리 화면은 마스터만 열 수 있습니다.
이 화면 자체는 섹션으로 나눠 줄 수 없습니다 — 맡기면 받은 사람이 스스로를 마스터로 올릴 수 있고, 마스터가 섹션을 전부 꺼도 되돌릴 문이 사라집니다.
