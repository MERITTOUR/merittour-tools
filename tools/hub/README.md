# MERITTOUR · 통합 점검 (hub)

엠클릭 엑셀들을 한 번에 올려 행사번호로 묶어 보는 도구입니다.

## 받아야 할 파일

| 파일 | 필수? | 비고 |
|---|---|---|
| 예약리스트 | 필수 | 미수·취소·회원권·예약구분 |
| 행사별마감현황 | 필수 | 손익(원가·마진) 유일한 출처 |
| 현지도착 | 필수 | 현지 시간·담당사원 |
| 일행별예약 | 권장 | 명단·여권·거래처 |
| APIS 정보 | 권장 | PNR·사전좌석 |
| 보험코드매칭 결과 | 선택 | 행사별 보험료 자동 채움 |

## 보험료 자동 연동

`tools/insurance/` 의 보험코드매칭 도구로 PDF + 예약을 매칭한 결과 엑셀을 hub 드롭존에 같이 던지면, 그 엑셀의 "행사별요약" 시트가 자동 인식돼 행사번호별 보험료 소계를 가져옵니다.

운영 탭 각 행의 자동 점검 배지에 보험료가 표시되고, 상세 모달의 보험료 칸에도 자동값이 채워집니다. 수동 메모는 별도로 적으실 수 있습니다.

## 탭 3개

**📋 예약 운영** — 행사 단위 백오피스. 자동 점검·OP 체크·발권 라벨·메모 3분류·운영 입력·손님 응답표·통합 엑셀 출력.
**💰 손익 점검** — 마진율 낮은순, 저마진/역마진 강조.
**🧾 미수·취소 위약금** — 미수 ≠ 0인 건과 취소 위약 건.

## 예약구분 → 발권 라벨 자동

예약리스트의 예약구분이 자동으로 발권 라벨이 됩니다.
- `.` → 그룹발권
- IND발권 → INDV발권
- 부분AIR → 일부개별
- AIR별도 → 항공만
- 항공대기 → 항공대기

수동으로 라벨을 바꾸면 그게 우선합니다.

## PNR

APIS에 있으면 행에 바로 표시됩니다. 콤마 이중 PNR은 첫 PNR만 사용합니다.

## 상품 기본값 (⚙ 우측 상단 버튼)

마감현황에 원가가 아직 없는 행사에 자동 적용됩니다.
- 항공권 / 보험 포함 여부
- 패키지가 (1인 정액 ₩)
- 1박 체재비 ¥ / 송영비 ¥ / 1박 수익 ¥
- 회원관리비 (1인 ₩, 기본 50,000)
- 기본 발권 라벨

JSON 내보내기·불러오기로 다른 PC와 룰 공유 가능.

## OP 입력 저장

확정서·견적서·예약금 체크, 비고 3분류, 운영 입력, 상품 기본값 — 모두 이 PC의 브라우저에 저장됩니다.

## 통합 엑셀 출력

화면에 보이는 행사들을 한 행씩 46개 컬럼(기본·항공·PNR·예약구분·자동/수동점검·OP체크·발권라벨·메모·운영입력·자동보험료·수동보험료메모)으로 저장합니다.
