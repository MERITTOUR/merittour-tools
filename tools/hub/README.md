# MERITTOUR · 통합 점검 (hub)

엠클릭 엑셀들을 한 번에 올려 행사번호로 묶어 한 화면에서 점검하는 도구입니다.
EWRC 업무관리 방식처럼 팀을 나누지 않고 한 테이블에 모든 운영 정보를 담되, 컬럼 묶음 토글로 보고 싶은 것만 펼칩니다.

## 받아야 할 파일

| 파일 | 필수? | 비고 |
|---|---|---|
| 예약리스트 | 필수 | 미수·취소·회원권·예약구분·진행구분 |
| 행사별마감현황 | 필수 | 손익(원가·마진) |
| 현지도착 | 필수 | 현지 시간·담당사원 |
| 일행별예약 | 권장 | 명단·여권·거래처 |
| APIS 정보 | 권장 | PNR·사전좌석 |
| 보험코드매칭 결과 | 선택 | 행사별 보험료 자동 |

## 운영 기본값 + 날짜별 일정 자동 생성

마스터(⚙) 화면 하단 "운영 기본값"에서 상품별로 송영·숙박·골프·식사·보험 기본 포함 여부와 규칙을 설정합니다.
- 골프: 평일 홀수(기본 27) / 주말·일본 공휴일 홀수(기본 18), 출국일·귀국일 골프 여부.
- 식사: 출국일·중간일·귀국일별 조·중·석식 패턴 (예: 귀국일 조식만).
- 송영: 첫날 픽업·마지막날 샌딩 / 보험: 기본 포함.

행을 클릭하면 상세에 **날짜별 일정이 자동으로 채워져** 표시됩니다. 출발~귀국을 날짜로 펼치고, 각 날짜의 요일·공휴일을 판정해 골프 홀수를 자동 배정, 식사·숙박·송영도 규칙대로 채웁니다. 주말은 노란색, 일본 공휴일은 빨간색 배경.
OP는 **예외만 수정**합니다(특정 날 골프 홀수 변경, 송영 빼기 등). 수정한 예외는 사이젠용 내보내기의 현지전달 컬럼에 "[일정예외]"로 자동 요약됩니다.

이로써 상품 기본값을 한 번 세팅해두면, 예약은 송영·숙박·골프·식사가 다 채워진 상태로 현지에 넘어가고, 현지는 예외만 확인하면 됩니다.

## 사이젠(현지)으로 넘기기

현지(야마나미)는 엠클릭 예약리스트를 사이젠 자동화 앱에 직접 올려 씁니다.
[📤 사이젠용] 버튼을 누르면 원본 예약리스트와 똑같은 컬럼 구조에 **현지전달 컬럼만 추가**한 엑셀이 나옵니다.
- 비고·그룹코드·팀명 등 사이젠이 읽는 기존 컬럼은 그대로 — 현지는 평소처럼 올리면 됩니다.
- hub 상세에서 OP가 "현지 전달" 칸에 적은 내용이 행사번호별로 현지전달 컬럼에 들어갑니다.
- 사이젠 앱(tools 밖 saizen/)은 이 현지전달 컬럼을 읽어 송영배정표 대표자 옆에 📋 本社伝達 배지로 표시(마우스 올리면 내용). 사이젠도 함께 업데이트하세요.

이 구조로 한국(메리트투어)은 정보 취합, 현지(사이젠)는 현지 업무로 역할이 분리됩니다.

## 상세 패널 입력 (EWRC 방식)

행을 클릭하면 하단 상세에서 바로 입력합니다.
- **특이사항 · OP 체크**: 명단업로드·INDV발권·AIR별도·사전좌석·현금영수증·확정서·견적서·예약금요청·예약금입금 (클릭 토글) + 발권 라벨.
- **특이사항 메모**: 체크 바로 아래 한 줄로 즉시 입력 (예: 휠체어, 앞좌석 요청, 대표자 변경). 입력하면 목록에 📌 표시.
- **비고**: 내부·항공팀·현지 전달 + 항공 정보.
- **운영 입력**: 방배정·골프조·식사/골프/룸 특이·보험료.

## 화면(컬럼) 직접 설정 — 톱니바퀴

상단 화면 줄에서 프리셋(영업·항공·현지·명단검수·전체)을 누르면 그 조합으로 컬럼이 세팅됩니다.
[⚙ 컬럼]을 누르면 설정 패널이 열려 개별 컬럼을 하나씩 켜고 끌 수 있습니다. 그룹별 "모두 켜기/끄기"도 있습니다.
내가 만든 컬럼 구성은 이 PC에 저장돼 다음에 열어도 유지됩니다. OP마다 자기 화면을 만들어 쓰면 됩니다.
[🔒 손익]은 비밀번호(기본 9800)를 넣어야 판매·원가·마진·마진율 컬럼이 켜집니다.

## 한 화면 + 컬럼 묶음 토글

상단 토글로 표시 컬럼을 켜고 끕니다. 누가 보든 같은 한 화면이라 정보 중복 입력이 없습니다.

- **기본** (항상) — 출발/귀국일·제목·그룹코드·출발지·패키지·인원·대표·진행(확정/정산/견적)·결제(완납/미수)
- **명단·여권** — 명단 상태·무기명·연락처 누락·여권 만료
- **항공** — 항공편·PNR·발권 라벨·항공권 포함·사전좌석·항공 비고(행에서 바로 입력)
- **현지·룸타입** — SGL/TWN/TRP/QUD/ETC 객실 수·방배정·골프조·보험료·현지 비고(행에서 바로 입력)
- **OP 체크** — 확정서·견적서·예약금·현금영수증·공휴일
- **🔒 손익** — 판매·원가·마진·마진율 (비밀번호 필요, 기본 숨김)

## 손익 / 마스터 잠금

손익 컬럼과 마스터 화면은 관리자 전용입니다. 비밀번호로 보호됩니다(기본 9800 — 회사 전화 끝자리).
EWRC가 입금액까지만 보여주고 수익은 노출 안 한 것과 같은 구분입니다. 운영 정보는 다 같이, 수익은 관리자만.

상단 우측 [💰 관리] = 손익 점검 + 미수·취소 위약금.
[⚙ 마스터] = 전체 통계 · 데이터 소스 · 상품 기본값 관리 · 전체 테이블 + 통합 엑셀(비밀번호).
제목 옆 "통합 점검" 배지를 누르면 통합 화면으로 돌아옵니다.

## 룸타입 (SGL/TWN/TRP/QUD/ETC)

현지·룸타입 토글을 켜면 행마다 객실 타입별 수량을 직접 입력합니다. 현지 담당이 방 구성을 한눈에 보고 채웁니다.

## 예약구분 → 발권 라벨 자동

`.`→그룹발권 / IND발권→INDV발권 / 부분AIR→일부개별 / AIR별도→항공만 / 항공대기→항공대기.

## 프론트오피스(회원 예약몰) 정합성

확정 패키지/변동 요금 구분, 일정 중 일본 공휴일(🎌), 예약번호(MT26) 인식 — 모두 v13 예약몰과 같은 개념.

## 화면 구성 (목록 + 하단 상세)

위쪽은 행사 목록(컬럼 토글·필터·일괄처리), 행을 클릭하면 화면 하단에 상세 패널이 고정으로 펼쳐집니다. 모달처럼 화면을 덮지 않아 목록을 보면서 상세를 다룰 수 있습니다.
- 다른 행을 클릭하면 하단 패널만 그 건으로 바뀝니다(목록은 그대로).
- 키보드 ↑↓ 로 행 이동, Esc로 닫기. 패널 상단 ↑↓ 버튼으로도 이동.
- 상세 패널 맨 위에 그 건의 문제점(무기명·여권만료·연락처누락·미수·사전좌석 미완)을 빨간 줄로 모아 표시 — 실수 방지.
- 상세 안: 기본정보 + 점검 배지 + OP체크/발권 + (좌)명단표 (우)비고 3분류·운영입력·손님 응답표.

## 팀 전달표 (담당자가 한눈에)

상단 [✈ 항공 전달표] / [🏨 현지 전달표] 버튼을 누르면, 지금 화면에 표시된(필터된) 행사들의 해당 팀 정보만 모은 표가 새 창에 떠서 인쇄·PDF·캡처할 수 있습니다.
- 항공 전달표: 출발일·항공편·PNR·발권·사전좌석·항공 비고
- 현지 전달표: 출발/귀국일·인원·대표/팀·SGL/TWN/TRP/QUD/ETC·방배정·골프조·보험료·현지 비고

담당자가 행마다 들어가지 않고 한 장으로 받아볼 수 있습니다. 골프장·출발월로 먼저 좁힌 뒤 뽑으면 깔끔합니다.

## 발권 라벨 · OP 체크

OP 체크(확정서·견적서 등)는 클릭으로 켜고, 다시 클릭하면 꺼집니다(토글).
발권 라벨에서 "미정"을 고르면 수동 설정이 지워지고 예약구분 자동값으로 돌아갑니다.

## 골프장 필터 · 팀 구분

상단 필터에 골프장(야마나미·포틴힐즈·스가다이라·간지호텔·아키바 등)이 추가됐습니다. 상품명에서 자동 추출됩니다.

비고에 적힌 팀 구분("김석진팀+정희채팀", "고용준팀(4) + 박상빈팀(4)", "김영희 + 김영기 팀" 등)을 자동 파싱해 대표 칸에 팀 배지로 표기하고, 행 클릭 시 모달에도 팀 구분이 나옵니다. 사이젠 방식과 동일합니다.

## 일괄처리

각 행 왼쪽 체크박스로 여러 행을 선택하면(헤더 체크박스로 전체 선택) 하단에 일괄처리 바가 뜹니다.
선택된 행들에 한 번에 적용: 발권 라벨 지정 · OP 체크(확정서·견적서·예약금·현금영수증) 켜기/해제 · 비고(내부/항공/현지) 입력.
엠클릭에선 어렵다던 일괄처리가 브라우저에서 동작합니다.

## 저장 / 향후

OP 입력은 이 PC 브라우저에 저장됩니다. 다음 단계로 Firebase를 붙이면 모든 직원 실시간 공유 + 엑셀 자동 수신.
