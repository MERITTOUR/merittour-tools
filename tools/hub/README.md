# MERITTOUR · 통합 점검 (hub)

엠클릭 엑셀들을 한 번에 올려 행사번호로 묶어 보는 도구입니다.

## 받아야 할 파일

| 파일 | 필수? | 비고 |
|---|---|---|
| 예약리스트 | 필수 | 미수·취소·회원권·예약구분 |
| 행사별마감현황 | 필수 | 손익(원가·마진) 유일한 출처 |
| 현지도착 | 필수 | 현지 시간·담당사원 |
| 일행별예약 | 권장 | 명단·여권·거래처 |
| APIS 정보 | 권장 | PNR·사전좌석 |
| 행사별정산현황 | 불필요 | 마감현황과 거의 동일 |
| 행사별수지계산서 | 불필요 | 자동으로 무시됨 |

## 탭 3개

**📋 예약 운영** — 행사 단위 백오피스. 자동 점검·OP 체크·발권 라벨·메모 3분류·운영 입력·손님 응답표·통합 엑셀 출력.
**💰 손익 점검** — 마진율 낮은순, 저마진/역마진 강조.
**🧾 미수·취소 위약금** — 미수 ≠ 0인 건과 취소 위약 건.

## 예약구분 → 발권 라벨 자동

예약리스트의 예약구분이 자동으로 발권 라벨이 됩니다.
- `.` → 그룹발권
- IND발권 → INDV발권
- 부분AIR → 일부개별
- AIR별도 → 항공만
- 항공대기 → 항공대기

수동으로 라벨을 바꾸면 그게 우선합니다(모달에 "수동" 또는 "예약구분 자동" 표시).

## PNR

APIS에 있으면 행에 바로 표시됩니다. 콤마로 된 이중 PNR은 첫 PNR만 사용합니다(룰).
검색창에서도 PNR로 찾을 수 있습니다.

## 상품 기본값 (⚙ 우측 상단 버튼)

마감현황에 원가가 아직 없는 행사에 자동 적용됩니다(7월 이후 출발 등).

키워드 매칭 방식 — 상품명에 키워드가 포함되면 적용. 위에서부터 매칭되는 첫 룰이 우선.

입력 항목:
- 항공권: 포함 / 개별발권
- 보험: 포함 / 미포함
- **패키지가 (1인 정액 ₩)** — 1박당 단가 무시하고 정액 사용
- 1박 체재비 ¥
- 송영비 ¥
- 1박 수익 ¥
- **회원관리비 (1인 ₩, 기본 50,000)**
- 기본 발권 라벨

체재비·송영비·수익·회원관리비는 정산 도구 만들 때 자동 계산에 그대로 들어갑니다.
JSON 내보내기·불러오기로 다른 PC와 룰 공유 가능합니다.

## 보험료

상세 모달의 운영 입력에 보험료 칸이 있습니다.
별도 PDF 검수 도구로 산출한 보험료 금액을 적어두시면 됩니다(향후 그 도구와 자동 연계 예정).

## OP 입력 저장

확정서·견적서·예약금 체크, 비고 3분류, 운영 입력, 상품 기본값 — 모두 이 PC의 브라우저에 저장됩니다.
다른 PC와 공유되지 않습니다. 본격 공유는 Firebase 단계에서 처리합니다.

## 톡·문자 안 보이는 이유

예약리스트의 톡·문자 컬럼이 비어 있어 자동으로 알림을 숨깁니다.
데이터가 들어오면 자동으로 다시 표시됩니다.

## 통합 엑셀 출력

화면에 보이는 행사들을 한 행씩 45개 컬럼(기본·항공·PNR·예약구분·자동/수동점검·OP체크·발권라벨·메모·운영입력·보험료)으로 저장합니다.
