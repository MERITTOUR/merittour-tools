# MERITTOUR · 통합 점검 (hub)

엠클릭 엑셀들을 한 번에 올려 행사번호로 묶어 보는 도구입니다.

## 받아야 할 파일 (정리됨)

| 파일 | 필수? | 비고 |
|---|---|---|
| 예약리스트 | 필수 | 미수·취소·회원권·항공코드 |
| 행사별마감현황 | 필수 | 손익(원가·마진) 유일한 출처 |
| 현지도착 | 필수 | 현지 시간·담당사원 |
| 일행별예약 | 권장 | 명단·여권·거래처 (APIS 대체) |
| APIS 정보 | 선택 | PNR·사전좌석 (notify 도구용) |
| 행사별정산현황 | 불필요 | 마감현황과 거의 동일 |
| 행사별수지계산서 | 불필요 | 자동으로 무시됨 |

## 탭 3개

**📋 예약 운영** — 행사번호 단위 백오피스. 검색·필터·자동 점검 배지·OP 체크(확정서/견적서/예약금 등)·발권 라벨·비고 3분류·운영 입력·손님 응답표.
**💰 손익 점검** — 마진율 낮은순으로 정렬, 저마진/역마진 강조, 출발지별 집계.
**🧾 미수·취소 위약금** — 미수 ≠ 0인 건과 취소인데 금액 남은 건.

## OP 입력 저장

확정서·견적서·예약금 체크, 비고 3분류, 운영 입력은 **이 PC의 브라우저**에 저장됩니다.
다른 PC와 공유되지 않습니다. 본격 공유는 Firebase 단계에서 처리합니다.

## 톡·문자 발송 표시 안 보이는 이유

받으신 예약리스트의 톡·문자 컬럼이 비어 있어 자동으로 그 알림을 숨깁니다.
엠클릭에서 발송 정보를 별도 화면에서 보시는 것 같으니, 향후 그 데이터가 들어오면 표시됩니다.

## 통합 엑셀 출력

화면에 보이는 행사들을 한 행씩, 모든 자동/수동 점검 결과와 OP 메모까지 포함해 xlsx로 저장합니다.
