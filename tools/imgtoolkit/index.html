📄 한글(HWP), 워드(DOCX), PPT, 엑셀 파일을 이미지로 만들고 싶다면?

이런 사무 문서들은 폰트와 레이아웃이 복잡해서 브라우저에서 직접 변환할 수 없습니다. 대신 PDF로 한 번 저장한 후 이 툴에 PDF를 올리면 페이지별 이미지로 변환됩니다.

한글 (HWP)

  1. 한글에서 파일 열기
  2. 상단 메뉴 파일 → PDF로 저장하기
  3. 저장된 PDF를 이 툴에 드래그

워드 (DOCX) / PPT / 엑셀

  1. 파일 열기
  2. 파일 → 다른 이름으로 저장 → 파일 형식: PDF 선택
  3. (또는 Ctrl+P → 프린터 선택에서 Microsoft Print to PDF)
  4. 저장된 PDF를 이 툴에 드래그

이미지 캡처가 더 간단한 경우

한두 장이면 그냥 Win + Shift + S (스니핑 도구)로 화면 캡처 후 PNG로 저장하는 게 빠릅니다.
