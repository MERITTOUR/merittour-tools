⑨ 요금 검증
리조트 마스터 단가 × 월별 환율 + 항공요금으로 예상 판매금액을 산출해 실제와 대조
계산식 · 예상 판매금액 = (체재비합 + 송영비합 + 엔화기타) × 출국월 환율 + 항공요금합 + 회원관리비합(₩50,000/인) + 원화기타. 환율·항공요금이 등록되지 않은 팀은 "기준 미등록"으로 표시됩니다. 리조트 마스터 → 월별 환율·항공요금 테이블을 먼저 채워주세요.

엠클릭 「호텔별 예약현황」 표를 드래그 → 복사(Ctrl+C) → 아래 칸에 붙여넣기(Ctrl+V). 파일 업로드·저장 없이 즉석 분석합니다.
일별 블록 현황 (보유 − 사용 = 잔여)
여유(잔여 4+) 임박(1~3) 마감/초과(0이하) · 임의배정형(구마모토 시내 등)은 사용수만 표시 · ← 좌우 스크롤
미분류 호텔 발견 · 아래 호텔은 ① 리조트 마스터에 등록돼 있지 않습니다. 리조트 마스터에서 해당 숙소의 룸타입 보유를 등록하거나, 표기가 다르면 별칭에 추가하면 잔여가 계산됩니다.
🛫 출발 가능 일정 조회
풀별 출발 패턴(목3박 등)으로 연박 구간 최소 잔여를 계산합니다. 연박 중 하루라도 마감이면 그 출발편은 막힘.
⏳ 대기 예약 → 전환 가능 점검
②예약 관리에서 통합 분석을 실행하면, 구분=대기 팀을 자동으로 뽑아 풀 잔여와 대조합니다. 별도 업로드 불필요.
판정 기준 · 팀의 숙소·출발일 기준 풀 잔여 ≥ 예약 인원이면 전환 가능. 풀 데이터(붙여넣기)가 없으면 "확인 필요". 실제 대기→확정 처리는 엠클릭에서 직접 하세요.
판매 가능 수량 시뮬레이션 · 웹 오픈 수량은 기본적으로 실 보유 블록 전체입니다. 백오피스(전화·카톡) 예약으로 사용이 늘면 웹잔여(=보유−사용)가 자동으로 줄어듭니다. 특정 날짜만 보유 초과로 더 팔 때(오버부킹) 그 칸의 수량을 보유보다 크게 올리세요. 상단 막대 = 사용/보유, 빨강 마커 = 보유 100% 지점.
야마나미 전기카트 · 객실이 아닌 이동수단(사전 신청 분량) 관리입니다. 엠클릭 표에 함께 입력된 전기카트 행을 분리해 보여줍니다. 숙소 합계에는 포함되지 않습니다.
메모: 서울 출발=출국 당일 라운딩 가능(박수만큼 배정), 부산 출발=귀국 라운딩분(출국 다음날부터 체크). 향후 출발지·일정 연동 자동 계산 검토.
⚙️ 호텔 블록 설정 안내
호텔 블록의 보유 블록 수·별칭·임의배정·출발 일정은 모두 ① 리조트 마스터에서 관리합니다. 숙소 정보가 한 곳에 모여 있어, 리조트 마스터만 수정하면 블록 현황·출발 일정 조회·대기 점검에 자동 반영됩니다.
