④ 요금 관리
요금 달력으로 출발일별 안내가를 산출하고, 표 보기로 실제 판매금액과 대조합니다
계산식 · 예상 판매금액 = (체재비합 + 송영비합 + 엔화기타) × 출국월 환율 + 항공요금합 + 회원관리비합(리조트 마스터 숙소별 값, 기본 ₩50,000/인) + 원화기타. 환율·항공요금이 등록되지 않은 팀은 "기준 미등록"으로 표시됩니다. 리조트 마스터 → 월별 환율·항공요금 테이블을 먼저 채워주세요.
패키지가(1인) · 벳푸 박수별·나가노 기간별처럼 항공까지 합쳐 단일가로 안내하는 상품은, 팀별 패키지가(1인) 칸에 1인 원화 총액을 넣으세요. 입력 시 분해식(체재비·송영비·항공·환율) 대신 패키지가 × 인원으로 산출되며, 숙소 옆에 「패키지」 배지가 붙고 분해 항목은 흐리게 표시됩니다. 동일한 패키지가는 리조트 마스터 → 패키지가 프리셋(숙소+박수)에 등록하면, 칸을 비워둬도 해당 팀에 자동 적용됩니다(「패키지·프리셋」 배지). 팀별 직접 입력값이 있으면 그게 우선입니다.
출발 가능 예약 있는 날
리조트와 출발지를 고르면 그 상품의 출발 패턴(목3박 등)이 달력에 깔립니다. 날짜를 클릭하면 그 출발편 기준으로 리조트 마스터 단가 + 그 달 안내 환율 + 항공요금을 정방향으로 분해한 안내 투어피 명세가 나옵니다. 「이 금액으로 판매하면 되는」 기준표이며, 싱글룸·사전좌석 등 개별 추가비는 별도입니다.

판매 가능 수량 시뮬레이션 · 웹 오픈 수량은 기본적으로 실 보유 블록 전체입니다. 백오피스(전화·카톡) 예약으로 사용이 늘면 웹잔여(=보유−사용)가 자동으로 줄어듭니다. 특정 날짜만 보유 초과로 더 팔 때(오버부킹) 그 칸의 수량을 보유보다 크게 올리세요. 여기서 말하는 「보유」는 그날의 마스터 보유(리조트 마스터의 기간 예외까지 반영한 값)입니다. 상단 막대 = 사용/보유, 빨강 마커 = 보유 100% 지점.
야마나미 전기카트 · 객실이 아닌 이동수단(사전 신청 분량) 관리입니다. 엠클릭 표에 함께 입력된 전기카트 행을 분리해 보여줍니다. 숙소 합계에는 포함되지 않습니다.
메모: 서울 출발=출국 당일 라운딩 가능(박수만큼 배정), 부산 출발=귀국 라운딩분(출국 다음날부터 체크). 향후 출발지·일정 연동 자동 계산 검토.
⚙️ 호텔 블록 설정 안내
호텔 블록의 보유 블록 수·별칭·임의배정·출발 일정은 모두 ① 리조트 마스터에서 관리합니다. 숙소 정보가 한 곳에 모여 있어, 리조트 마스터만 수정하면 블록 현황·출발 일정 조회·대기 점검에 자동 반영됩니다.
리조트 마스터에서 설정하는 항목
  • 룸타입별 보유 블록 — 예: 아소 야마나미 골프텔 트윈 55 / 소형트윈 50
  • 기간별 보유 예외 — 특정 기간만 보유가 다를 때(성수기 증실·객실 보수 등). 하루짜리도 가능. 겹치면 짧은 기간이 우선. 마스터 내보내기에 함께 실려 전 직원에게 배포됩니다
  • 엠클릭 표기 별칭 — 예: 14hills → 포틴힐즈CC 골프텔, 소테츠/다이와 → 구마모토 시내 호텔
  • 임의배정 여부 — 블록을 미리 안 까는 숙소(구마모토 시내). 잔여 계산 대신 사용수만 표시
  • 출발 일정·출발/도착 공항 — 출발 일정 조회에 사용

정산
현지정산(¥) + 수익(체재마진·항공수익·총수익) 통합 · 구분/거래유형/출발지 필터 · 항공원가 입력
구분:
먼저 업로드 탭에서 파일을 올리고 [통합 분석 실행]을 누르면 정산이 표시됩니다.
업로드 전에도 ① 리조트 마스터의 현지정산단가와 항공요금 테이블은 미리 입력해둘 수 있습니다.
현지정산 + 수익 · 숙박비 = 인원 × 박수 × 현지정산단가(① 리조트 마스터 숙소별 값), 송영비 = 인원 × 송영 단가. 체재마진(¥) = 박수 × (안내 체재비 − 현지정산단가) — 야마나미 예: 박당 ¥1,000. 항공수익(₩) = 안내가(마스터 항공요금) − 항공원가(입력). 총수익(₩) = 체재마진 × 출국월 환율 + 항공수익. 항공조인·AIR별도·구마모토 시내는 항공 0 처리됩니다. 항공원가는 행마다 직접 입력하거나, 「항공원가 입력틀」을 내보내 채운 뒤 「항공원가 불러오기」로 일괄 반영할 수 있습니다.
