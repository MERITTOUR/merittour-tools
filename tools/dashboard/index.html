PNR · 콤마로 나뉜 PNR은 발권이 여러 건으로 분리된 것이며 모두 표기됩니다. 일행 명단은 APIS·일행별예약에서 자동 보완되며, 영문명·생년월일·여권·만료일을 함께 확인할 수 있습니다.
점검 칩 · 입력 누락·최신화 누락 건을 잡기 위한 필터입니다. PNR 미등록(미발권), 사전좌석 Y(좌석 요청 처리 필요), 출발·귀국편 누락(편명 미입력), 항공사 불일치(예약리스트의 항공 표기와 APIS 항공사가 어긋남 — 최신화 누락 의심).
출발지 칩 · 인천·김해·대구 등 출발 공항별로 거를 수 있습니다(데이터에 있는 출발지로 자동 생성, 복수 선택 가능).

④ 요금 검증
리조트 마스터 단가 × 월별 환율 + 항공요금으로 예상 판매금액을 산출해 실제와 대조
계산식 · 예상 판매금액 = (체재비합 + 송영비합 + 엔화기타) × 출국월 환율 + 항공요금합 + 회원관리비합(리조트 마스터 숙소별 값, 기본 ₩50,000/인) + 원화기타. 환율·항공요금이 등록되지 않은 팀은 "기준 미등록"으로 표시됩니다. 리조트 마스터 → 월별 환율·항공요금 테이블을 먼저 채워주세요.
패키지가(1인) · 벳푸 박수별·나가노 기간별처럼 항공까지 합쳐 단일가로 안내하는 상품은, 팀별 패키지가(1인) 칸에 1인 원화 총액을 넣으세요. 입력 시 분해식(체재비·송영비·항공·환율) 대신 패키지가 × 인원으로 산출되며, 숙소 옆에 「패키지」 배지가 붙고 분해 항목은 흐리게 표시됩니다. 동일한 패키지가는 리조트 마스터 → 패키지가 프리셋(숙소+박수)에 등록하면, 칸을 비워둬도 해당 팀에 자동 적용됩니다(「패키지·프리셋」 배지). 팀별 직접 입력값이 있으면 그게 우선입니다.
출발 가능 예약 있는 날
리조트와 출발지를 고르면 그 상품의 출발 패턴(목3박 등)이 달력에 깔립니다. 날짜를 클릭하면 그 출발편 기준으로 리조트 마스터 단가 + 그 달 안내 환율 + 항공요금을 정방향으로 분해한 안내 투어피 명세가 나옵니다. 「이 금액으로 판매하면 되는」 기준표이며, 싱글룸·사전좌석 등 개별 추가비는 별도입니다.

판정 기준 · 팀의 숙소·출발일 기준 풀 잔여 ≥ 예약 인원이면 전환 가능. 풀 데이터(붙여넣기)가 없으면 "확인 필요". 실제 대기→확정 처리는 엠클릭에서 직접 하세요.
판매 가능 수량 시뮬레이션 · 웹 오픈 수량은 기본적으로 실 보유 블록 전체입니다. 백오피스(전화·카톡) 예약으로 사용이 늘면 웹잔여(=보유−사용)가 자동으로 줄어듭니다. 특정 날짜만 보유 초과로 더 팔 때(오버부킹) 그 칸의 수량을 보유보다 크게 올리세요. 상단 막대 = 사용/보유, 빨강 마커 = 보유 100% 지점.
야마나미 전기카트 · 객실이 아닌 이동수단(사전 신청 분량) 관리입니다. 엠클릭 표에 함께 입력된 전기카트 행을 분리해 보여줍니다. 숙소 합계에는 포함되지 않습니다.
메모: 서울 출발=출국 당일 라운딩 가능(박수만큼 배정), 부산 출발=귀국 라운딩분(출국 다음날부터 체크). 향후 출발지·일정 연동 자동 계산 검토.

사이젠 現地精算表 대조용 · 숙박비 = 인원 × 박수 × 현지정산단가(① 리조트 마스터의 숙소별 값), 송영비 = 인원 × 송영 단가. 체재·송영 면제와 단가 보정은 「개인별 명세」에서 반영됩니다. 사이젠과 동일하게 항공조인·구마모토 시내 상품은 제외합니다. 차감(쿠폰·포인트·선납)을 입력하면 실정산액 = 총액 − 차감합계로 계산됩니다 — 사이젠 화면과 항목·금액이 같으면 정산이 맞은 것입니다.
사전 지불 · 쿠폰 · 포인트 차감 관리 — 메리트투어 선납·차감분. 실정산액(총액 − 차감합계) 자동 계산
예: 싱글차지 선납 / 쿠폰 차감 / 적립금 사용 / 포인트 할인
차감 합계 ¥0 실정산액 ¥0
엠클릭 행사별정산현황과 같은 분해 · 지상비 = 현지정산액(¥) × 출국월 환율 · 체재마진 = (안내 체재비 − 현지정산단가) × 박수 × 환율 · 알선수익 = 판매금액 − 발권원가 − 지상비 − 보험료 · 알선수수료 = 알선수익 ÷ 1.1 (부가세 분리) · 총수수료 = 알선수수료 + 체재마진. 발권원가는 항공요금 테이블의 「발권원가」 칸 → 개인별 일괄/개별 입력 순으로 적용됩니다.
값 우선순위 · 발권가: 개별 > 일괄 > 테이블(항공요금 테이블 발권원가) · APIS에 항공편·PNR이 없는 인원은 지상만으로 발권가 0원 처리(개별 입력으로 변경 가능). 체크박스는 Shift 클릭으로 범위 선택이 되고, 필터를 건 뒤 「보이는 행 전체 선택」으로 엑셀 필터처럼 묶어 입력할 수 있습니다. 입력 칸을 비우면 테이블/기본값으로 되돌아갑니다. 보험료는 DB손해보험 가입증명서 PDF를 올리면 피보험자 명세(성명·생년월일·인별보험료)를 읽어 자동 입력됩니다(PDF 배지). PDF·일괄·개별은 같은 칸에 쓰며 마지막 입력이 적용됩니다.
