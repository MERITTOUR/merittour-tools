⚙ 풀(검색 단위) 설정

풀은 "검색 단위"입니다. 야마나미처럼 여러 호텔·룸을 통합 운영할 때 한 풀로 묶습니다. 각 풀에서 키워드로 자동 매칭하거나 호텔명·룸타입을 명시할 수 있습니다.

설정 형식 안내 (클릭)
· 키워드: 호텔명에 포함된 문자열. 예: 아소 → "아소"가 들어간 모든 호텔 자동 포함
· 호텔(쉼표 구분): 정확한 호텔명을 직접 명시. 예: 14hills, 포틴힐즈CC 골프텔
· 룸 필터(쉼표 구분): 풀에 포함할 룸 타입. 비우면 모든 룸. 예: 트윈, 소형트윈
· Capacity: 야마나미처럼 인원수 단위 운영일 때 만실 한도. 비우면 잔여수 기반 계산
· 출발 일정: 요일 + 박수 형식. 예: 목3박, 일4박, 수7박 = 목요일출발 3박 + 일요일출발 4박 + 수요일출발 7박
    비우면 패턴 없음 = 일자별 잔여만 표시 / 자유로 적으면 모든 요일 출발 가능 (닐라이용)

⚠ 어느 풀에도 매핑되지 않은 호텔·룸
