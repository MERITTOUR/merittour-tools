# MERITTOUR 사내 도구함

엠클릭(Mclick) 데이터를 기반으로 영업·운영 업무를 돕는 단일 HTML 도구 모음입니다.
GitHub Pages로 배포되며, 진입점은 영업 도구함(`/sales/`)입니다.

|---|---|---|
| 통합 안내 대시보드 | `tools/dashboard/` | 엠클릭 3종+APIS를 행사번호(eventSeq)로 묶어 예약·항공·보험·송영·숙소·골프·식사를 한 화면에서 점검. 비고 팀 구분 모달, 출국 임박(D-30/7/1), 선택 팀 알리고 PNR 안내 양식 내보내기 |

## 통합 안내 대시보드 (dashboard)

엠클릭 예약리스트·일행별예약·현지도착 + APIS 정보를 한 번에 올리면, 모든 데이터를 행사번호(eventSeq)로 묶어 8개 섹션으로 정리합니다.

### 받는 파일

| 파일 | 필수? | 비고 |
|---|---|---|
| 예약리스트 | 필수 | 구분·호텔·명단·미수금·판매금액·비고 |
| 일행별예약 | 필수 | 개인(탑승객) 명단 |
| 현지도착 | 권장 | 현지 도착/출발 시간·회원권구분 보완 |
| APIS 정보 | 권장 | PNR(콤마 분리 전부)·항공사·사전좌석·여권 |

500건 분할 시 같은 종류 파일 여러 개를 동시에 올리면 자동 병합됩니다. 그룹코드 마스터는 사용하지 않습니다.

### 섹션

1. **리조트 마스터** — 리조트별 체재비·송영비·식사 단가, 환율, 여행자보험 (입력값 자동 저장)
2. **예약 관리** — 전체 현황·호텔/명단/미수금, 비고 팀 구분 모달, 출국 임박 모달, 알리고 양식 내보내기
3. **보험 정보** — 팀별 여권(번호·만료일·국가), 여권 만료 임박 경고, 보험 가입 체크
4. **항공 정보** — 일행 전원·항공사·편명·사전좌석·PNR(콤마 전부)·발권완료 체크·출국 안내
5. **송영 정보** — 입국/출국편·현지 시간·송영비
6. **숙소 정보** — 숙소별 팀·인원·룸타입 집계
7. **골프 정보** — 상품명 기준 골프장 분류
8. **식사 정보** — 식사 인원·연인박 집계

### 알리고 PNR 안내 양식

예약 관리 또는 항공 정보에서 발송할 팀을 체크하고 [선택 팀 알리고 양식] 버튼을 누르면,
알리고 알림톡 업로드용 xlsx가 생성됩니다(수신번호 + 고객명·일자·상품명·출발지·도착지·편명·PNR).
체크인 타이밍·공항 도착·카운터 안내 문구는 알리고 템플릿이 처리하므로, 도구는 치환변수만 채웁니다.
