# MERITTOUR · 통합 점검 (hub)

엠클릭 엑셀들을 한 번에 올려 행사번호로 묶어 한 화면에서 점검하는 도구입니다.
EWRC 업무관리 방식처럼 팀을 나누지 않고 한 테이블에 모든 운영 정보를 담되, 컬럼 묶음 토글로 보고 싶은 것만 펼칩니다.

## 받아야 할 파일

| 파일 | 필수? | 비고 |
|---|---|---|
| 예약리스트 | 필수 | 미수·취소·회원권·예약구분·진행구분 |
| 행사별마감현황 | 필수 | 손익(원가·마진) |
| 현지도착 | 필수 | 현지 시간·담당사원 |
| 일행별예약 | 권장 | 명단·여권·거래처 |
| APIS 정보 | 권장 | PNR·사전좌석 |
| 보험코드매칭 결과 | 선택 | 행사별 보험료 자동 |

## 한 화면 + 컬럼 묶음 토글

상단 토글로 표시 컬럼을 켜고 끕니다. 누가 보든 같은 한 화면이라 정보 중복 입력이 없습니다.

- **기본** (항상) — 출발/귀국일·제목·그룹코드·출발지·패키지·인원·대표·진행(확정/정산/견적)·결제(완납/미수)
- **명단·여권** — 명단 상태·무기명·연락처 누락·여권 만료
- **항공** — 항공편·PNR·발권 라벨·항공권 포함·사전좌석·항공 비고(행에서 바로 입력)
- **현지·룸타입** — SGL/TWN/TRP/QUD/ETC 객실 수·방배정·골프조·보험료·현지 비고(행에서 바로 입력)
- **OP 체크** — 확정서·견적서·예약금·현금영수증·공휴일
- **🔒 손익** — 판매·원가·마진·마진율 (비밀번호 필요, 기본 숨김)

## 손익 / 마스터 잠금

손익 컬럼과 마스터 화면은 관리자 전용입니다. 비밀번호로 보호됩니다(기본 9800 — 회사 전화 끝자리).
EWRC가 입금액까지만 보여주고 수익은 노출 안 한 것과 같은 구분입니다. 운영 정보는 다 같이, 수익은 관리자만.

상단 우측 [💰 관리] = 손익 점검 + 미수·취소 위약금.
[⚙ 마스터] = 전체 통계 · 데이터 소스 · 상품 기본값 관리 · 전체 테이블 + 통합 엑셀(비밀번호).
제목 옆 "통합 점검" 배지를 누르면 통합 화면으로 돌아옵니다.

## 룸타입 (SGL/TWN/TRP/QUD/ETC)

현지·룸타입 토글을 켜면 행마다 객실 타입별 수량을 직접 입력합니다. 현지 담당이 방 구성을 한눈에 보고 채웁니다.

## 프론트오피스(회원 예약몰) 정합성

확정 패키지/변동 요금 구분, 일정 중 일본 공휴일(🎌), 예약번호(MT26) 인식 — 모두 v13 예약몰과 같은 개념.

## 저장 / 향후

OP 입력은 이 PC 브라우저에 저장됩니다. 다음 단계로 Firebase를 붙이면 모든 직원 실시간 공유 + 엑셀 자동 수신.
