# MERITTOUR 사내 도구함

엠클릭(Mclick) 데이터를 기반으로 영업·운영 업무를 돕는 단일 HTML 도구 모음입니다.
GitHub Pages로 배포되며, 진입점은 영업 도구함(`/sales/`)입니다.

## 도구 목록 (`tools/`)

| 도구 | 경로 | 설명 |
|---|---|---|
| 통합 업무 허브 | `tools/dashboard/` | 엠클릭 데이터를 한데 모아 예약·항공·보험·송영·숙소·골프·식사·요금검증·호텔블록을 한 화면에서 점검하는 메인 도구 |
| 보험코드매칭 | `tools/insurance/` | 보험사 PDF + 예약 엑셀 → 인별/행사별 보험료 자동 매칭 |
| 이미지 툴킷 | `tools/imgtoolkit/` | WebP 변환·리사이즈·압축. 엠클릭 백오피스용 이미지 최적화 |
| 리조트 날씨 | `tools/weather/` | 리조트별 현지 날씨 예보 + 손님 안내문 복사 |

> 기존 `예약가능일자 안내(inquiry)` 도구는 통합 업무 허브의 ⑩ 호텔 블록 탭으로 흡수되어 제거되었습니다.

## 통합 업무 허브 (dashboard)

엠클릭 데이터를 한데 모아 더 편하게 점검·집계·발송 대상 추출을 하는 메인 도구입니다.
엠클릭이 본체 ERP이고, 이 도구는 그 데이터를 모아 조회·검증을 보조합니다.

### 받는 파일 (엠클릭 3종 + APIS, eventSeq로 결합)

| 파일 | 필수? | 비고 |
|---|---|---|
| 예약리스트 | 필수 | 구분·호텔·명단·미수금·판매금액·비고 |
| 일행별예약 | 필수 | 개인(탑승객) 명단 |
| 현지도착 | 권장 | 현지 도착/출발 시간·회원권구분 보완 |
| APIS 정보 | 권장 | PNR(콤마 분리 전부)·항공사·사전좌석·여권 |

예약리스트는 500행씩 분할 다운로드, 일행별예약은 1개월 단위로 명단 인원수와 무관하게 한 번에 다운로드됩니다. 여러 달이거나 분할분이 생기면 같은 종류 파일 여러 개를 동시에 올리면 자동 병합됩니다. 그룹코드 마스터는 사용하지 않습니다.

### 섹션 (① ~ ⑩)

1. **리조트 마스터** — 리조트별 체재비·송영비·식사 단가, 환율(월별 테이블), 항공요금 테이블, 여행자보험. 입력값 자동 저장
2. **예약 관리** — 전체 현황·호텔/명단/미수금, 비고 팀 구분 모달, 출국 임박(D-30/7/1) 모달, 알리고 양식 내보내기, 컬럼 정렬
3. **보험 정보** — 팀별 여권(번호·만료일·국가), 여권 만료 임박 경고(출국 6개월 미만), 보험 가입 체크
4. **항공 정보** — 일행 전원·항공사·편명·사전좌석·PNR(콤마 전부)·발권완료 체크·출국 안내
5. **송영 정보** — 입국/출국편·현지 시간·송영비(¥6,000/인)
6. **숙소 정보** — 숙소별 팀·인원·룸타입 집계
7. **골프 정보** — 상품명 기준 지역·골프장 분류
8. **식사 정보** — 식사 인원·연인박 집계
9. **요금 검증** — 리조트 마스터 단가 × 월별 환율 + 항공요금으로 예상 판매금액 산출 → 실제와 대조
10. **호텔 블록** — 엠클릭 「호텔별 예약현황」 표를 붙여넣어 즉석 분석. 블록 현황(보유−사용=잔여)·출발 가능 일정 조회(연박 최소잔여)·대기 전환 점검·판매 시뮬레이션·전기카트·보유/풀 설정

### ⑩ 호텔 블록 탭 요약

- **입력**: 엠클릭 화면 표를 드래그 복사 → 붙여넣기(Ctrl+V). 파일 업로드·저장 없이 휘발성으로 즉석 분석(직전 입력만 브라우저에 임시 보관)
- **보유 마스터**: 호텔×룸타입별 1일 보유 블록(실데이터 내장, 수정 가능). 풀 정원은 보유 합산으로 자동 도출
- **풀(검색 단위)**: 키워드(예: 아소)·호텔명·룸필터로 묶음. 출발 패턴(목3박 등)으로 연박 잔여 계산
- **통합/실물 보기**: 구마모토 시내(소테츠·다이와)처럼 묶어 파는 호텔을 통합(영업용)/실물(수배용)로 전환
- **임의배정형**: 구마모토 시내처럼 블록을 미리 안 까는 호텔은 잔여 계산 대신 사용수만 표시
- **별칭**: 14hills = 포틴힐즈CC 골프텔 등 표기 차이 흡수
- **전기카트**: 객실이 아닌 이동수단이라 숙소 매트릭스에서 분리해 별도 집계
- **공지 PNG**: 예약가능일자 공지 이미지 생성(네이비 표준폼)

### 알리고 PNR 안내 양식

예약 관리 또는 항공 정보에서 발송할 팀을 체크하고 [선택 팀 알리고 양식] 버튼을 누르면,
알리고 알림톡 업로드용 xlsx가 생성됩니다(수신번호 + 고객명·일자·상품명·출발지·도착지·편명·PNR).
체크인 타이밍·공항 도착·카운터 안내 문구는 알리고 템플릿이 처리하므로, 도구는 치환변수만 채웁니다.

## 기술 표준

- 단일 HTML 파일 기반. 외부 라이브러리는 CDN(cdnjs)에서 로드(xlsx=SheetJS, html2canvas)
- 로고는 인라인 SVG, 데이터 저장은 localStorage(키 네임스페이스 `mt_notify_*`)
- 라이트 모드 고정, 메리트투어 네이비/블루그레이 색상 표준

## 배포

GitHub Pages. 진입점은 `/sales/`이며 루트 `index.html`은 `/sales/`로 리다이렉트합니다.
도구 경로 규칙: `tools/{toolname}/index.html`
