# 로고 파일

| 파일 | 무엇 |
|---|---|
| `logo-merittour-horizontal.svg` | 심볼 + MERITTOUR 워드마크 (가로형 원본) |
| `logo-merittour-mark.svg` | **심볼만** — 가로형에서 떼어낸 벡터. 크기를 바꿔 쓸 때는 이것부터 |
| `logo-merittour-mark-94.png` | 94×94 · 흰 바탕 |
| `logo-merittour-mark-800.png` | 800×800 · 흰 바탕 — **프로필 사진에 쓸 것** |
| `logo-merittour-mark-800-navy.png` | 800×800 · 네이비 바탕에 흰 심볼 |
| `logo-merittour-mark-800-alpha.png` | 800×800 · 배경 투명 |

브랜드 색 = `#373f4a`

## 프로필 사진(유튜브·카카오 등)에 쓸 때

- **800px 를 올린다.** 유튜브는 98×98 이상을 권하지만 실제로는 채널 페이지에서
  176px, 관리 화면에서는 더 크게 그린다. 작게 올리면 늘려서 흐려진다.
  줄이는 것은 깨끗하고 늘리는 것은 안 깨끗하다.
- **바탕은 흰색을 쓴다.** 심볼이 네이비(`#373f4a`)라 배경이 투명하면 다크 테마에서
  거의 안 보인다. 네이비 바탕 판은 흰 심볼이라 다크에서도 뜨지만, 라이트 테마에서
  검은 동그라미로 보이니 쓰는 곳을 보고 고른다.
- **동그랗게 잘린다.** 그래서 심볼을 정사각형 폭의 **72%** 로만 넣었다. 꽉 채우면
  잎 끝이 잘린다.

## 다시 만들 때

`logo-merittour-mark.svg` 를 정사각 캔버스 가운데에 폭 72% 로 놓고 원하는
크기로 내보내면 된다. 원본 심볼 비율은 85.26 × 67.32 (가로가 더 길다).
